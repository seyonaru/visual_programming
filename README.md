## Задания 
- написать функцию, конвертирующую CSV текст в JSON формат
- написать функцию, конвертирующую CSV файл в JSON файл
- написать модульный тест для первой функции
- написать mock-тест для второй функции

## Основные моменты выполнения лабораторной работы
- для корректной отладки (тестирования) в исполняемом коде нужно прописывать ошибки и делать проверки на существование
- при передаче индексов создавать константы для корректной работы
- для работы с файлами нужно использовать асинхронные функции
- обязательно проверять иерархию всех скобок

## Структура проекта в ветке
````
visual_programming/
├── .github/
│   └── workflows/
│       └── ci.yml                    # GitHub Actions workflow для CI/CD: автоматический запуск тестов при push
├── dist/                             # Скомпилированные JavaScript файлы (результат работы TypeScript компилятора)
├── node_modules/                     # Зависимости проекта, установленные через npm (не коммитятся в git)
├── src/                              # Исходный код проекта на TypeScript
│   ├── main/                         # Основная логика приложения
│   │   ├── index.ts                  # Точка входа, экспорт и реализация всех функций
│   └── test/                         # Тесты для проекта
│       ├── index.test.ts             # Главный тестовый файл (может импортировать другие тесты)
├── .gitignore                        # Список файлов и папок, которые git должен игнорировать (не отслеживать)
├── package-lock.json                 # Автоматически генерируемый файл с точными версиями всех зависимостей
├── package.json                      # Конфигурация проекта: зависимости, скрипты (test, build), метаданные
├── tsconfig.json                     # Конфигурация TypeScript компилятора (target, module, strict mode и т.д.)
└── vitest.config.ts                  # Конфигурация тестового фреймворка Vitest (настройки запуска тестов)
````
